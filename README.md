# AXIOM Design Studio — Website Concept

A cinematic, responsive website concept for an architecture and interior design studio, built with React and Vite.

## Features

- Full-screen architectural hero
- Editorial portfolio layout for architecture and interior design
- Responsive desktop and mobile layouts
- Self-hosted typography
- Interactive navigation and section transitions

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Project Status

Independent website concept prepared for review. This is not an official commissioned website unless separately approved. Architectural visualizations are illustrative concepts and should not be interpreted as evidence of completed projects.
